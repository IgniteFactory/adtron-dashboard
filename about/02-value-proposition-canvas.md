# 价值主张画布 — 红薯榜单 (Redlist)
**产品／服务：** 共享小红书网红营销活动
**客户细分：** 马来西亚餐饮业中小企业商家（咖啡馆、餐厅为主）
**类型：** B2B
**阶段：** 问题-解决方案契合（假设阶段，待真实商家数据验证）

---

## 客户画像

### 客户任务（按重要性排序）

**功能性任务**
1. 吸引更多从未来过的新顾客走进店里
2. 在小红书上建立可被搜索到的品牌存在感
3. 在有限预算内执行真正有效的营销活动
4. 将营销执行外包出去，让自己专注于经营本业

**社交性任务**
5. 被同行认可为"懂得做营销"的商家
6. 进入权威推荐榜单，建立品牌可信度

**情感性任务**
7. 对营销决策感到有把握，而不是焦虑和不确定
8. 感觉自己终于在做"真正的营销"，而不只是发发帖子

---

### 客户痛点（按严重程度排序）

**极度痛苦**
1. 花了钱但没有带来新顾客——曾经花RM 800找博主合作，结果只来了三个粉丝，零新顾客
2. 传统小红书网红营销费用远超预算（RM 10,000–60,000），根本负担不起
3. 自己联系、管理、跟进20位博主极其耗时，且专业门槛高

**中度痛苦**
4. 无法控制内容——不知道博主最终会写什么、怎么呈现自己的品牌
5. 不知道会和哪些商家并排，担心被差口碑商家拉低品牌形象
6. 很难判断一次营销活动是否真的有效，无法追踪投资回报

**潜在风险**
7. 不确定小红书平台是否可持续，担心RM 2,000打水漂
8. 没有足够的小红书算法知识，无法自己运作推广

---

### 客户期望收益（按重要性排序）

**必须有**
1. 有真实的、陌生的新顾客走进来，并提到在小红书上看到她
2. 帖子内容质量好，不会让品牌显得廉价或不专业

**理所当然**
3. 明确知道帖子什么时候发布，大约多久看到效果
4. RM 2,000的投入，带来可量化、可感知的新客流量

**期望但惊喜**
5. 在相关搜索关键词下多次出现，形成搜索主导地位
6. 被同行问"你是怎么在小红书上排名的"——社交认可

**意外惊喜**
7. 同榜的互助引流效果——用户搜索同榜其他商家时，也看到她
8. 与"天花板级"知名商家并列，间接提升品牌调性

## 价值地图

### 产品与服务

- 共享网红营销活动（每期5–8家互补商家共同参与）
- 20位小红书博主协调发布，覆盖2–3周发布窗口
- 合集帖（榜单）内容格式（"KL最值得去的8家咖啡馆"等）
- 全程代为执行：博主brief、内容制作、质量审核、发布排期
- 精选、合约签约博主网络（真实粉丝、高质量内容、无刷量记录）
- "天花板光环效应"——每份榜单纳入同城公认的顶流商家（非付费）
- 商家门户——提交照片素材与关键卖点

---

### 痛点解决方案（对应具体痛点）

| 解决方案 | 对应痛点 |
|---|---|
| 固定收费RM 2,000，透明无隐藏费用 | 预算有限，传统网红营销费用远超承受范围 |
| 20篇帖子同期覆盖，而非单篇合作 | 单次博主合作效果微弱，曾被坑过 |
| 全程代为执行，商家只需提供照片与卖点 | 自己管理20位博主耗时且专业门槛高 |
| 内容经过质量审核，发布前把关 | 无法控制博主最终写什么 |
| 注重互补性的商家搭配，用心筛选同榜商家 | 担心与差口碑商家并列 |
| 发布时间表清晰，商家知道确切节点 | 无法追踪效果，不知何时看到结果 |
| 价格仅为市场行情的1/5至1/30 | 花了钱但无法确保ROI |

---

### 收益创造（对应具体期望收益）

| 收益创造 | 对应期望收益 |
|---|---|
| 20篇帖子覆盖小红书搜索结果，形成搜索饱和 | 被搜索到时多次出现，形成主导地位 |
| 榜单格式自带权威感与"不去可惜"的稀缺感 | 帖子内容专业，不会让品牌显得廉价 |
| 与天花板级知名商家并列 | 提升品牌调性，被认可为值得去的好店 |
| 互助引流效应——同榜商家互相为对方带客 | 额外获得意料之外的新顾客来源 |
| 商家无需管理执行细节，只需提交一次素材 | 专注本业，营销全部交给团队 |
| 参与"榜单"，成为被推荐的对象而非主动打广告 | 被同行问"你怎么做到的"——社交认可 |

## 契合度评估

### 强契合点（覆盖良好）

- **价格壁垒被彻底移除** ← RM 2,000对比市场的RM 10,000–60,000，价值主张无可争辩
- **"被坑过"的心理障碍被正面回应** ← 20篇帖子的量级 + 质量审核，直接对比单篇合作的弱势
- **执行全包** ← 直接解决了"我没时间、没专业知识"的核心障碍
- **榜单效应与社交认同** ← 创造了"被推荐"而非"在打广告"的心理体验

### 缺口（覆盖不足或薄弱）

- **内容质量的透明度** ← 商家在付款前无法预览内容风格；需要案例库和博主主页浏览权限来弥补
- **平台持续性风险** ← 目前没有针对"小红书会不会消失"这个顾虑的正面回应
- **首批验证案例的缺失** ← 处于软上线阶段，真实ROI数据还在积累；这是短期内最脆弱的环节
- **对新顾客流量的可追踪性** ← 商家很难把来客精准归因到榜单；缺乏"如何追踪效果"的工具或引导

---

### 契合阶段评估

**当前阶段：问题-解决方案契合（假设阶段）**

价值主张在逻辑上成立，各元素对应关系清晰。但距离产品-市场契合，还需要至少3–5个有ROI数据支撑的真实商家案例。

**最关键的下一步验证：**
找到第一批愿意公开分享"进店客流量变化"的付费商家，将他们的真实数据转化为销售武器。

---

### 核心洞察

红薯榜单的价值主张有一个清晰的强势核心：用中小企业能承受的价格，给他们大品牌才能享有的曝光策略。这个逻辑简单、直接、有力。但现在最脆弱的地方只有一个——缺乏可验证的ROI证明。在早期销售阶段，弥补这个缺口比任何功能优化都重要。
